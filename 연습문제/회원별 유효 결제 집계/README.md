# 회원별 유효 결제 집계

- 풀이일: 2026-09-25
- 구분: 자체 제작 SQL 연습문제
- 기준 DBMS: MySQL 8.0
- 유형: REGEXP, 문자열 정규화, CTE, GROUP BY, LEFT JOIN, COALESCE
- 목적: 유효한 결제 메모를 검증하고 전화번호 형식을 통일한 뒤 모든 회원의 결제 건수와 금액을 집계하기

## 핵심 조건

- 결제 메모는 PAY: 뒤에 010XXXXXXXX 또는 010-XXXX-XXXX만 정확히 허용한다.
- 앞뒤 추가 문자·공백, 잘못된 하이픈 위치, CANCEL:, NULL 등은 제외한다.
- 기간은 2026-09-01 00:00:00 이상, 2026-10-01 00:00:00 미만이다.
- 메모와 회원 전화번호는 하이픈을 제거한 값으로 연결한다.
- 유효 결제가 없는 회원과 PHONE이 NULL인 회원도 0건·0원으로 출력한다.
- 금액 0인 결제도 건수에는 포함한다.
- TOTAL_AMOUNT 내림차순, MEMBER_ID 오름차순으로 정렬한다.

## 최종 풀이 흐름

1. REGEXP로 원본 MEMO 형식을 먼저 검증한다.
2. SUBSTRING으로 PAY:를 제거한다.
3. REPLACE로 하이픈을 제거해 전화번호를 정규화한다.
4. 정규화된 전화번호 기준으로 결제 건수와 금액을 집계한다.
5. MEMBERS를 기준으로 LEFT JOIN해 결제가 없는 회원도 보존한다.
6. COALESCE로 NULL 집계값을 0으로 바꾼다.

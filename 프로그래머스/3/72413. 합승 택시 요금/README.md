## 풀이 핵심

동승을 끝낼 지점 `k`를 하나 고르면 전체 비용은

```text
거리(s, k) + 거리(k, a) + 거리(k, b)
```

가 됨. 모든 `k` 중 최솟값을 구하면 됨. `k=s`도 고려하므로 처음부터 합승하지 않는 경우도 포함함. 무방향 그래프여서 `dist(a,k)=dist(k,a)`이고 출발지 `s, a, b`에서 각각 최단거리를 계산하면 충분함.

**중요:** 기존에 `dijkstra`라고 이름 붙인 함수는 일반 FIFO 큐를 사용하므로 **엄밀한 의미의 다익스트라가 아님**. 양수 가중치에서 거리가 줄어들 때마다 정점을 다시 처리하는 큐 기반 거리 완화 방식. 이 문제의 조건에서는 올바른 결과를 구하지만 재탐색으로 효율성이 떨어질 수 있음.

## 다음에 기억할 것

1. **설계 성공의 분기점:** 경로들을 직접 시뮬레이션하지 말고, **합승 종료 지점 하나를 고정**하면 문제를 3개의 최단경로 계산으로 환원할 수 있음.
2. **다익스트라:** *현재 정점의 이웃 중 최소 간선 요금*이 아니라 **지금까지 발견한 전체 미확정 정점 중 출발점에서의 누적 비용이 가장 작은 정점**을 꺼내 최단거리를 확정.
3. **거리 초기화:** `0`을 미방문과 실제 거리 두 용도로 쓰지 말고 `INF`로 초기화, `dist[start]=0`.
4. **오래된 우선순위 큐 항목:** `if (cost > dist[node]) continue;`로 건너뛰기.
5. **플로이드–워셜:** `dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`; 경유지 `k`가 반드시 가장 바깥 반복문.
6. **인접 리스트와 행렬:** 이웃 순회에는 리스트, 두 정점 사이 직접 연결 여부·요금 조회에는 행렬.

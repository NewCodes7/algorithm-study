- [상세 피드백 및 정리한 코드](./FEEDBACK_2026-09-26.md)

복습 포인트: 포인터 이동과 보석 개수 갱신을 함께 처리하기, 중첩 반복문의 복잡도를 전체 이동 횟수의 합으로 계산하기, getOrDefault로 개수 누적을 단순화하기.

평균 시간 복잡도 **O(N)**, 추가 공간 **O(K)**. N은 보석 수, K는 보석 종류 수.

검증 범위: 원본 로직을 Python으로 옮겨 작은 입력 9,840개를 완전탐색과 비교함. Java 컴파일·실행 및 프로그래머스 비공개 채점은 수행하지 않음.

각 Java 파일은 프로그래머스 제출 형식인 `class Solution`을 사용하므로 **하나씩 별도로 컴파일·실행**함. 개선안은 사용자 작성 원본과 구분함.

복습할 때는 상세 피드백의 첫 표와 **1~5번 DP 사고 과정**, **7번 다익스트라 비교표**부터 확인하기.

## 로컬 검증

- Java 17에서 네 Java 파일을 각각 수정 없이 별도 컴파일함.
- 공식 예제 2개를 포함한 고정 입력 15개와 무작위 입력 500개, 총 **515개 입력 × 4개 구현 = 2,060회 결과 확인**을 통과함.
- 초기 능력치 초과, 목표 0, 한쪽 목표 0, 보상 초과, 보상 0, 중복 문제, 요구 능력치 150·문제 수 100 경계를 포함함.
- 작은 입력은 목표 상한 처리를 하지 않는 **시간별 실제 능력치 집합 탐색**을 독립 기준으로 사용함. 무작위 시드: `118668`.
- 이는 로컬 검증 결과이며 프로그래머스 전체 채점 결과를 의미하지 않음. 검증용 코드는 임시 실행 환경에서만 사용하고 제출용 파일에는 포함하지 않음.

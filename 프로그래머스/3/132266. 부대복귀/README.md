## 가장 중요한 복습

1. 여러 시작점에서 동일한 목적지까지의 최단거리: **무방향 그래프라면 목적지에서 BFS 한 번**.
2. BFS에서 노드마다 sources를 순회하면 **O(VS)** 비용이 발생함.
3. `dist[]`를 -1로 초기화해 방문 여부와 거리를 같이 저장하고, BFS 후 `answer[i] = dist[sources[i]]`로 조회하기.

복잡도: 최초 O(S(V+E)) → 재풀이 O(V+E+VS) → 개선 O(V+E+S).

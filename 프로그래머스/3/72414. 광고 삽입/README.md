## 빠른 복습

1. 로그별 구간 전체 순회는 최악 약 1,080억 회 → **차분 배열**은 시작 +1, 끝 -1만 기록.
2. 차분 배열에 누적합을 적용하면 실제 시청자 수. 원본은 윈도우를 이동하며 필요한 시점의 누적값만 계산함.
3. 광고 구간은 **`[start, start+advTime)`**. 슬라이딩 시 나가는 시각 `start-1`, 들어오는 시각 `start+advTime-1`.
4. 합계는 **`long`**, 동률은 먼저 찾은 시작 시각 유지(`>`로만 갱신).
5. **풀이 변경 후 전체 시간복잡도 재점검.** 모든 업데이트가 끝난 뒤 조회하면 차분 배열이 적합. 업데이트와 조회가 섞이면 펜윅 트리·세그먼트 트리 검토.

**복잡도:** 로그 수 `L`, 초 단위 영상 길이 `T`일 때 시간 `O(L+T)`, 추가 공간 `O(T)`.

원본과 피드백을 구분해서 보존함. 별도의 플랫폼 재채점은 수행하지 않았으며, 합격 여부는 사용자의 보고에 근거함.

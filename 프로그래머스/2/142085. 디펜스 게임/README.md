핵심: 지금까지 등장한 적 중 가장 큰 k개를 무적권 대상으로 관리하되, 실제 사용 위치는 저장하지 않는다. 병사 소모량은 변경되는 항목 하나만 갱신한다.

시간복잡도 O(M log(k+1)), 추가 공간 O(k). M은 적 라운드 수이고 k≥1이다.

검증: Java 컴파일 성공, 공식 예시 1 결과 5 확인, 난수 생성 입력 20,000건을 각 접두 구간의 비용을 별도로 계산한 기준 풀이와 대조하여 모두 일치함. 프로그래머스 비공개 채점은 수행하지 않음.

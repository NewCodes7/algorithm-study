# 디펜스 게임 풀이 피드백 — 2026-10-13

- 문제: [프로그래머스 142085 / 디펜스 게임](https://school.programmers.co.kr/learn/courses/30/lessons/142085)
- 유형: 그리디, 우선순위 큐
- 소스: [디펜스 게임.java](./디펜스 게임.java) — 코드·주석은 사용자 원문 그대로 보존
- 사용자 풀이 기록: 약 57분. 초기 49분 시점 시간 초과·실패(68.8점), 힌트 후 84.4점·실패를 기록. 최종 코드의 공식 재채점 결과는 확인하지 않음.

## 피드백 핵심

1. **그리디 기준:** 무적권을 실제로 사용한 위치를 추적할 필요 없음. 현재 라운드까지 등장한 적 가운데 **가장 큰 k개**를 무적권 대상으로 유지하기. 미래의 적을 미리 고를 필요도 없음.
2. **상태 최소화:** 처음 시도한 적의 인덱스, pass 배열, Enemy 클래스는 필요 없음. 현재 풀이에서는 정수 우선순위 큐와 병사 소모량 sum만으로 충분함. 현재 코드의 answer 변수도 사용되지 않음.
3. **재계산 대신 증분 갱신:** 새로운 적이 기존 무적권 대상 중 최솟값보다 크면 대상을 교체하면서 기존 최솟값만 병사 비용으로 더함. 작거나 같으면 새 적의 수만 비용에 더함. 매번 앞에서 다시 순회하지 않기.
4. **최종 의사코드에서도 시간복잡도 확인:** **처음 아이디어를 떠올릴 때만 계산하는 것이 아님.** 풀이를 구체화하고 **최종 의사코드를 완성한 뒤, 구현 직전에도** 시간복잡도가 제한에 맞는지 다시 점검하기. 설계 중 추가한 전체 재순회 때문에 앞선 풀이가 최악 O(M²)이 되었음.
5. **복잡도 비교:** 앞선 방식은 최악 O(M²). 현재는 우선순위 큐 크기를 k로 제한하므로 O(M log(k+1)), 추가 공간 O(k). M은 enemy 배열의 길이.
6. **중첩 클래스와 비교 문법:** Comparable<Enemy>를 구현하면 compareTo(Enemy other)는 상대 객체 하나를 받음(Comparator의 compare(a, b)와 다름). 바깥 Solution 인스턴스를 참조하지 않는 중첩 클래스는 private static class가 적절하지만, 이번 최종 풀이에서는 클래스 자체가 불필요함.
7. **정수 비교와 제약 확인:** this.count - other.count는 이번 적 수 범위(1~1,000,000)에서는 오버플로하지 않음. 일반적인 int 비교는 Integer.compare(a, b)가 안전하며, 두 인자가 int 범위 안에 있다면 직접 대소 비교하므로 뺄셈 오버플로가 없음. int를 넘는 값을 비교하려면 long과 Long.compare를 사용하기.

## 이번 풀이에서 바로잡을 사고방식

- 처음 메모의 “무적권을 처음부터 다 써버리면 불리하다”는 표현은 정확하지 않음. 앞의 k개를 임시 무적권 대상으로 잡더라도, 이후 더 큰 적이 나오면 대상 하나를 교체할 수 있으므로 불리하지 않음.
- **불변식:** 각 라운드 종료 시 큐에는 현재까지 적 중 큰 k개(현재 등장 수가 k보다 적다면 전부), sum에는 나머지 적의 누적 수가 들어감.
- 이 상태에서 sum이 n을 초과하면 현재 접두 구간에서 가능한 병사 소모의 최솟값조차 n을 초과한다는 뜻이므로 이후 라운드는 막을 수 없음.

## 검증 기록

- 문제 제한: 1 ≤ n ≤ 10⁹, 1 ≤ k ≤ 500,000, 1 ≤ enemy[i] ≤ 1,000,000. 따라서 이전에 언급했던 k=0 처리는 이 문제에서 필요하지 않음.
- sum은 통과한 상태에서 n 이하이고 추가 비용은 최대 1,000,000이므로, 이 코드의 sum + 비용은 int 범위를 벗어나지 않음.
- Java로 컴파일하고 난수 20,000건(길이 1~30, k 1~10, n 1~100, 적 1~40)을 접두 구간을 별도로 정렬해 계산한 기준 풀이와 비교했으며 모두 일치함.
- 공식 예시 1: n=7, k=3, enemy=[4,2,4,5,3,3,1] → 결과 5 일치.
- 프로그래머스 비공개 채점은 수행하지 않았으며, 과거 68.8점/84.4점은 사용자 회고 메모에 기록된 값임.

복습 포인트: BFS의 큐·방문 배열·시작점 삽입·시작점 방문 처리를 한 묶음으로 기억하기, 큐에 넣을 때 방문 처리하기, 실패 사례를 전부 나열하기보다 큐 소진으로 탐색 실패를 처리하기, 상태마다 다음 상태를 찾는 비용까지 복잡도에 포함하기.

시간 복잡도 **O(nm(n + m))**, 추가 공간 **O(nm)**. n은 행 수, m은 열 수.

검증 범위: 대화에 제공된 최종 코드를 정적으로 검토함. 이번 커밋에서는 Java 컴파일·실행 및 프로그래머스 비공개 채점을 수행하지 않음.

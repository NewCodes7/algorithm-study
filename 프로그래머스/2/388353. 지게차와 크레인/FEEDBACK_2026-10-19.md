## 복습용 핵심 피드백 (사용자 작성 4항목을 점검·정리)

1. **처음 check()를 재귀 DFS처럼 구현했다가 오답·런타임 에러 발생.**
   - **DFS 자체가 틀린 것은 아님.** 첫 방향에서 재귀가 false를 반환하면 그대로 `return check(...)`로 종료해, 다른 방향에 출구가 있어도 확인하지 않는 것이 **오답의 원인**. '외부로 가는 길이 하나라도 있으면 성공'인 문제에서는 **true일 때만 즉시 반환하고, false라면 다른 방향도 탐색**해야 함.
   - **런타임 에러 원인: StackOverflowError.** 방문 표시 없는 재귀에서 인접한 빈칸들을 왕복하면 호출이 끝없이 쌓일 수 있음. DFS도 그래프·격자에서 사이클 가능성이 있으면 `visited`를 써야 함.
   - 대표 런타임 에러·예외: `StackOverflowError`, `NullPointerException`, `ArrayIndexOutOfBoundsException` 등. 재귀 코드 런타임 에러면 **반복 방문 / 종료 조건**부터 확인.
   - 예제는 통과했어도 **순환 방문을 일으키는 구조나 특정 갈림길**이 드러나지 않았을 수 있음. 재귀 호출 자체가 없었다는 뜻은 아님.
   - 실전: 기존 예제 실행에 그치지 말고 **빈칸 사이클, 막힌 첫 분기+열린 다른 분기, 동시 제거**를 직접 소형 반례로 만들어 테스트. 시간 여유가 있다면 코드 검토 및 직접 만든 반례 검증.

2. **한 글자 문자열 → 문자 변환:** `request.charAt(0)`로 충분. `char target = request.charAt(0);`처럼 한 번 추출해 써도 좋음.

3. **BFS 큐의 타입과 구현체:** `Queue<int[]>` 가능 (`int[]`는 참조형 배열). `Queue<int[]> queue = new ArrayDeque<>();`를 기본 선택으로. 일반적인 FIFO 큐에서 `LinkedList`보다 유리한 경우가 많으나 모든 상황에서 무조건 빠른 것은 아님.

4. **최적화 과제:** 현재는 대상 컨테이너마다 별도 BFS를 수행함. 지게차 요청마다 **외부와 연결된 빈칸을 시작점으로 한 번만 BFS**한 뒤, 인접한 목표 컨테이너를 제거 대상으로 표시하는 풀이도 나중에 직접 구현해 보기. 테두리 대상 컨테이너는 직접 접근할 수 있으므로 별도 고려.

## 추가로 꼭 기억할 것

- **동시 제거 처리:** 이번 요청에서 제거할 컨테이너는 일단 `'t'`로 표시한 뒤, 요청 처리가 끝나면 `'x'`로 바꿈. 이번 요청에서 새로 뚫린 길을 같은 요청의 판정에 사용하지 않기 위한 올바른 방법임.
- **시간복잡도 재검토:** 단순히 50×50×100으로 계산하면 각 칸에서 다시 수행하는 BFS를 놓침. `N = 행×열`, `Q = 요청 수`일 때 현재 코드 최악 시간 `O(Q×N²)`, BFS 한 번으로 개선하면 `O(Q×N)`. 방문 배열을 각 check()에서 새로 만드는 비용까지 고려.
- **경계 검사:** 수정한 check()에서 테두리 좌표를 만나면 이웃 탐색 전에 즉시 true를 반환하므로, 그 다음 이웃 `map[newX][newY]` 접근은 내부 칸에서만 수행되어 이 구현에서는 범위 밖 접근이 발생하지 않음. 외부 기준 BFS로 바꿀 때는 경계 검사 필요.

## 반례 체크 메모

~~~java
// 초안 재귀에서 방문 없이 같은 빈칸을 왕복할 수 있음 → StackOverflowError
storage = new String[]{"CCCCC", "CABBC", "CCCCC"};
requests = new String[]{"BB", "A"}; // 기대 13

// 첫 방향이 막혔어도 다른 방향이 외부로 연결되어 있음 → 탐색을 계속해야 함
storage = new String[]{"CBC", "CAC", "CBC", "CCC"};
requests = new String[]{"BB", "A"}; // 기대 9

// 지게차 요청은 '요청 시작 시' 접근 가능한 8개만 제거 → 가운데 A는 남아야 함
storage = new String[]{"AAA", "AAA", "AAA"};
requests = new String[]{"A"}; // 기대 1
~~~

이번 복습 포인트: DR/DC 방향 배열, 큐 삽입 시 방문 표시, 모든 BFS의 비용 합산, 덩어리별 mark 순회 비용, 최소·최대 열로 집계하기.

원본 시간복잡도 O(NM + KM), 최악 O(NM²). 개선 예시 O(NM). N은 행, M은 열, K는 덩어리 수.

## 복습 요약 (앞으로 기억할 것)

1. **집계값과 개별 행을 동시에 사용**하려면 `집계 CTE + 원본 테이블 JOIN` 또는 **윈도우 함수**를 떠올리기.
2. `GROUP BY`는 각 그룹을 대표하는 집계 행으로 줄이고, `MAX(...) OVER (PARTITION BY ...)`는 **원본 행을 유지하면서** 그룹별 집계값을 각 행에 붙인다.
3. 이번 문제는 원본 데이터의 모든 연도가 `MAX_SIZE`에 있으므로 `LEFT JOIN` 대신 **`INNER JOIN`**을 써도 된다. 단, 외부 조인이 필요한 문제까지 무조건 바꾸면 안 됨.
4. 컬럼은 가능하면 `YEAR(A.DIFFERENTIATION_DATE)`처럼 **테이블 별칭을 명시**해 출처를 명확히 하기.
5. `OVER` 안의 `ORDER BY`는 **윈도우 계산 순서**, 가장 바깥 `ORDER BY`는 **최종 출력 순서**를 정한다.

## 이번에 작성한 원본 쿼리

```sql
WITH MAX_SIZE AS (SELECT YEAR(DIFFERENTIATION_DATE) AS YEAR, MAX(SIZE_OF_COLONY) AS SIZE
FROM ECOLI_DATA
GROUP BY YEAR(DIFFERENTIATION_DATE))
SELECT B.YEAR, (B.SIZE - A.SIZE_OF_COLONY) AS YEAR_DEV, A.ID
FROM ECOLI_DATA A LEFT JOIN MAX_SIZE B ON YEAR(DIFFERENTIATION_DATE) = B.YEAR
ORDER BY B.YEAR, YEAR_DEV

-- 09:34~09:39 5분
```

- `YEAR(DIFFERENTIATION_DATE)`별 최대 크기를 CTE에서 구하고, 각 대장균 행에 연결해 `MAX - SIZE_OF_COLONY`를 구한 풀이.
- 정렬 조건 `ORDER BY B.YEAR, YEAR_DEV`도 문제와 일치.
- 5분 만에 요구사항을 정확히 CTE + JOIN 구조로 옮겼다는 점이 강점.

## 최소한으로 개선한 쿼리

```sql
WITH MAX_SIZE AS (
    SELECT YEAR(DIFFERENTIATION_DATE) AS YEAR,
           MAX(SIZE_OF_COLONY) AS SIZE
    FROM ECOLI_DATA
    GROUP BY YEAR(DIFFERENTIATION_DATE)
)
SELECT B.YEAR,
       B.SIZE - A.SIZE_OF_COLONY AS YEAR_DEV,
       A.ID
FROM ECOLI_DATA A
JOIN MAX_SIZE B
    ON YEAR(A.DIFFERENTIATION_DATE) = B.YEAR
ORDER BY B.YEAR, YEAR_DEV;
```

- 원본의 `LEFT JOIN`을 `JOIN`으로 바꾸고, 날짜 컬럼의 테이블 별칭을 명시함.
- 연도별 CTE에 대응되는 연도가 없는 원본 행은 문제의 구조상 없음.

## 새로 알아둘 문법: PARTITION BY

```sql
SELECT YEAR(DIFFERENTIATION_DATE) AS YEAR,
       MAX(SIZE_OF_COLONY) OVER (
           PARTITION BY YEAR(DIFFERENTIATION_DATE)
       ) - SIZE_OF_COLONY AS YEAR_DEV,
       ID
FROM ECOLI_DATA
ORDER BY YEAR, YEAR_DEV;
```

- `OVER`는 윈도우 함수를 적용하는 절이며, `PARTITION BY`는 계산 대상을 그룹별로 나눈다.
- 이 방식은 원본 행을 유지하므로 별도 CTE 및 JOIN 없이 같은 결과를 구한다.
- **더 짧게 쓰는 것이 항상 더 빠른 실행을 뜻하지는 않는다.** 성능은 실행 계획과 데이터에 따라 다르다.

### 다음 단계: 그룹별 순위

```sql
ROW_NUMBER() OVER (
    PARTITION BY YEAR(DIFFERENTIATION_DATE)
    ORDER BY SIZE_OF_COLONY DESC, ID ASC
)
```

- `ROW_NUMBER()`: 각 그룹 안에서 서로 다른 순번 부여. 동률일 때 결과를 재현하려면 `ID` 같은 추가 정렬 키를 둘 것.
- `RANK()`: 정렬 기준 값이 같으면 공동 순위 부여하고, 다음 순위를 건너뛴다.
- `NTILE(4)`: 정렬된 행들을 가능한 한 비슷한 크기의 4개 구간으로 나눈다.
- `MAX()/SUM() OVER (PARTITION BY ... ORDER BY ...)`처럼 집계 윈도우 함수에 `ORDER BY`를 넣으면 기본 윈도우 프레임으로 인해 누적 계산이 될 수 있음. 그룹 전체 집계만 필요하면 `ORDER BY`를 생략하자.

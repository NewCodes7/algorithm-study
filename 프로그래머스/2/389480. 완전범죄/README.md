# [level 2] 완전범죄 - 389480

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/389480?language=java)

- 풀이 기록 저장일: 2026-10-15
- 유형: 다이나믹 프로그래밍(DP), 상태 압축, 각 물건의 A/B 선택
- 풀이 경과: 완전탐색의 2^40 경우를 고민 → Queue에 (A, B) 상태를 저장하고 가지치기 시도 → m ≤ 120을 활용하는 DP로 전환. DP 상태 정의를 설명받은 후 최종 Java 코드는 직접 작성함.
- **[완전범죄.java](./완전범죄.java)**: 사용자 최종 풀이와 주석을 원문 그대로 저장
- **[상세 피드백](./FEEDBACK_2026-10-15.md)**: 상태 정의, 가지치기와 DP의 연결, 전이 구현, 재풀이 질문
- **[재풀이 대기 목록](../../../RETRY_PROBLEMS.md)**

핵심 질문: **“모든 경우의 수를 기억해야 할까? 아니면 특정 조건이 같은 경우들 중 최적의 값 하나만 기억하면 될까?”** 이 문제에서는 같은 B 흔적이라면 최소 A 흔적만 기억하면 된다.

- DP: `dp[b] = B 흔적이 정확히 b일 때 가능한 최소 A 흔적` (`-1`은 불가능)
- 시간복잡도: O(L × m), 추가 공간복잡도: O(m) (L = 물건 수; L ≤ 40, m ≤ 120)
- 검증: Java 21 컴파일, 공식 예제 4개 통과. 길이 1~12, n/m 1~13, 흔적 1~3의 난수 30,000건을 완전탐색과 비교하여 전부 일치(시드 389480).
- 프로그래머스의 비공개 채점 결과는 별도로 확인하지 않았음.

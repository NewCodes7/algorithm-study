# 완전범죄 풀이 피드백 — 2026-10-15

- 문제: [프로그래머스 389480 / 완전범죄](https://school.programmers.co.kr/learn/courses/30/lessons/389480)
- 유형: DP, 상태 압축, 0/1 선택
- 코드: [완전범죄.java](./완전범죄.java) — 사용자가 작성한 최종 코드와 원본 주석 보존
- 검증: Java 21 컴파일 성공; 공식 예제 4개와 완전탐색을 기준으로 한 무작위 30,000개 입력 일치. 프로그래머스 비공개 채점은 수행하지 않았음.

## 풀이 과정에서 배울 점

1. **먼저 완전탐색의 선택지를 정확히 찾음.** 물건 하나마다 A/B 두 선택이 있으므로 최대 `2^40`. Queue로 (A 흔적, B 흔적)을 전부 누적하면 상태 수가 급증할 수 있음.
2. **가지치기 사고는 DP로 가는 징검다리였음.** `(A1,B1)`이 `(A2,B2)`보다 양쪽 흔적 모두 작거나 같으면, 같은 개수의 물건을 처리한 상태에 한해 후자를 버려도 됨. `(3,2)`와 `(3,2)`처럼 A/B 각각이 모두 같은 상태는 하나면 충분함. **단순히 A+B의 합만 같은 것은 중복이 아님.**
3. **제한을 보고 저장 상태를 바꿈.** 물건 수는 최대 40개지만 `m`은 최대 120. 상태를 전부 기억하는 대신 B 흔적별로 묶을 수 있음.
4. **상태 정의:** `dp[b]` = 현재까지 처리한 물건들에서 **B 흔적이 정확히 b**인 상태 중 **A 흔적의 최솟값**. 불가능한 상태는 `-1`.
5. **같은 B 흔적이면 최소 A만 남겨도 되는 이유:** 이후 남은 물건의 선택지는 동일하고 B 출발점도 같음. A 흔적이 더 큰 상태는 어떤 후속 선택을 하더라도 더 좋아질 수 없음. 즉, 최적해에 필요 없는 세부 경로를 압축함.
6. **전이는 이전 단계의 `dp`에서 다음 단계의 `newDp`로.** A가 훔치면 B 인덱스 유지 / A 흔적 증가, B가 훔치면 B 인덱스 증가 / A 흔적 유지. 매번 `< n`, `< m`이어야 함. **같은 물건을 여러 번 사용하는 오류**를 피하려면 이번 단계에서 만든 값을 다시 이번 단계의 출발점으로 쓰지 않기.
7. **현재 코드의 B 전이에서 `newDp[j+b] = dp[j]`가 안전한 이유:** 해당 물건의 b 증가량이 고정되어 서로 다른 `j`가 같은 `j+b`에 도착하지 않음. B 전이를 먼저 전부 수행하고 A 전이에서 `newDp[j]`와 최솟값을 비교하기 때문에 괜찮음. 두 전이를 한 반복문으로 합치거나 전이 순서를 바꾼다면 충돌을 포함해 다시 검토할 것.
8. **초깃값과 표현 간소화:** `Arrays.fill(dp, -1)`을 사용하면 수동 초기화 반복문을 줄일 수 있음. 첫 물건을 별도 처리한 코드는 제한상 (`info.length >= 1`) 정상. 일반화하면 `dp[0] = 0`으로 시작해 모든 물건을 `i=0`부터 같은 전이로 처리할 수 있음. 다만 원본 코드는 변경하지 않음.

## 이번 문제에서 일반화할 사고방식

> **“모든 경우의 수를 기억해야 할까? 아니면 특정 조건이 같은 경우들 중 최적의 값 하나만 기억하면 될까?”**

**완전탐색 → 불필요한 상태 판별 → 상태 압축 가능성 발견 → DP 상태 정의와 전이 검토**의 순서로 사고하기.

- 단순히 상태를 압축할 수 있다는 사실만으로 모든 문제가 DP가 되는 것은 아님. **지금 남긴 정보만으로 다음 선택의 결과를 정확히 계산할 수 있는지**(상태의 충분성), 동일 조건끼리 최솟값을 남기는 것이 안전한지 확인할 것.
- 이 문제는 **같은 B 흔적**에 대해 **최소 A 흔적** 하나만 기억해도 모든 다음 전이를 수행할 수 있으므로 `dp[b]`로 충분함.
- 흔적 합계만 같은 두 상태를 같은 상태로 취급하면 안 됨. `(A,B)` 각각과 제약 조건을 따로 고려할 것.
- 기존 Queue 기반 접근에서 `list.size()`를 반복문 조건에 직접 쓰면 `offer()`로 길이가 바뀌며 반복 대상이 달라짐. 기존 단계 상태 수를 미리 저장하거나 DP 단계 배열을 분리하는 방식으로 해결.
- 이 문제의 시간복잡도는 `O(L × m)` (`L ≤ 40, m ≤ 120`), 공간은 `O(m)`. 두 번의 m 순회도 상수 배이므로 차수는 같음.
